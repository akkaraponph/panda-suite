# v1.3.0 — Panda Learn

Panda Suite adds `panda-learn`, bringing the catalog to 21 independent skills.
It implements the supplied Codebase Learning & Engineering Mentor proposal as a
standalone, source-backed teaching workflow with read-only defaults.

## Changes

- Overview, exploration, deep dive, execution tracing, architecture, concept
  translation, guided learning and quick explanations selected from natural requests.
- Actual source references, explicit evidence conflicts and unknowns, qualified
  design rationale and language analogies, and proportionate depth.
- Optional one-question learning checkpoints that wait for a learner response;
  direct answers do not require quizzes, saved documents or a selector UI.
- Lead routing and overlap rules, English/Thai catalogs, full usage guide and
  generated Learn documentation page.
- Ten evaluation scenarios, a small order-service fixture and a reviewer-only
  correct control that distinguishes a retry contract gap from passing ordinary tests.
- Actual fresh-context baseline/candidate trials with preserved answers and
  explicit shared-filesystem, settings and sample-size limitations.

## Evidence and compatibility

See [Learn's contract and evaluation](panda-learn.md), the
[comparison record](../tests/results/learn/comparison.md) and the
[release verification record](../tests/results/learn/verification.md) for actual
results. Package checks, discovery and model behavior are reported separately.
The sampled baseline already handled the learning tasks; the release does not
claim that a new skill is necessary for ordinary explanations or that it produces
measured reliability, speed, token or learning-outcome improvements.

Portable and Claude manifests advance from 1.2.0 to 1.3.0. Existing names and
invocation formats remain supported. No new service, dependency or migration is
required; pinned upstream sources and attribution remain unchanged. Return to
v1.2.0 for the previous catalog. Preserve customized installed skills before
replacing them; publishing source does not refresh installed plugin caches.
