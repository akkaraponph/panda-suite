# v1.6.2

This release updates planning handoffs and document authoring across the 23-skill
Panda Suite. It includes the changes prepared on `feature/1.6.2-rc` through the
release commit.

## Panda Plan and Execute

- When a user makes an authoritative scope decision, Plan updates the full saved
  plan and checks for stale references to removed work.
- Execute applies settled scope changes to the plan, removes descoped tasks and
  checks, and proceeds with the remaining authorized work. It asks only when
  scope is still unclear.

The refinement adds blind cases for Plan and Execute scope changes. Existing
planning and execution cases remain regression controls.

## Panda Write

- New documents are grouped under `.panda-suite/docs/<story-slug>/`; the skill
  asks when the request does not identify a story folder clearly.
- Supplied DOCX templates guide formatting, including styles and page layout.
  Template content is not treated as factual evidence unless the user says so.
- Writing guidance now targets clear, evidence-linked language for product
  managers, project managers, and technical leads when that audience is relevant.
- On macOS, the documented DOCX export path can use the already available
  `textutil` command. The skill does not install conversion software. DOCX
  template fidelity still depends on what the available conversion tools can
  read and reproduce.

Blind cases cover DOCX template fidelity and the Thai PM/Tech Lead writing
register. These cases are prepared for evaluation; they do not establish a
behavioral improvement by themselves.

## Verification and limits

On the local 1.6.2 release candidate, the structural validator passed for all 23
skills, their local references, manifests, and scenario coverage. The
documentation build created 44 pages; the link checker passed across 44 pages
and 2,514 internal links. The tooling suite passed all 30 tests. `git diff
--check` passed.

These checks cover packaging, generated documentation, repository tooling, and
the whitespace state. Scenario definitions and fixture checks are not substitutes
for fresh baseline-versus-skill model evaluations. Behavioral comparisons for the
new refinements remain **Not Run**.

## Compatibility and recovery

No application runtime dependencies or migrations are introduced. Plugin
manifests advance to 1.6.2. Existing local plugin installations may need an
update or reinstall to load the new instructions. The previous source version is
available at [v1.6.1](v1.6.1.md).
