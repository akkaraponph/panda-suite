# v1.6.1

This patch release tightens the commit boundaries in `panda-git` and documents
the updated skill in the generated GitHub Pages site.

## Panda Git changes

- A commit request stays within Git operations. It does not authorize code fixes,
  refactors, or amending an existing commit. A new commit is the default.
- Files larger than 10 MiB require explicit confirmation naming the file before
  inclusion in a commit.
- Detected secrets and credentials stay out of commits. The skill reports their
  paths and concern without exposing values.
- Sensitive or credential-like configuration and files that appear ignored,
  generated, local, or environment-specific must be listed with a reason and
  confirmed path by path before inclusion. Existing staging is not consent.
- Added blind scenarios for commit-only scope, large files, secret-bearing `.env`
  files, and files force-added despite `.gitignore` rules.

## Verification and limits

`./.venv/bin/python scripts/validate-skills.py` validated 23 skills, their local
references, manifests and scenario coverage. `./.venv/bin/python
scripts/build-docs.py` built 43 pages; `./.venv/bin/python
scripts/check-docs.py` checked 2,413 internal links with no broken targets or
fragments. The new behavioral scenarios are present but **Not Run**; this release
makes no claim that a fresh model evaluation has verified their behavior. Secret
detection is best-effort and is not a comprehensive scan.

## Compatibility and recovery

No runtime dependencies or application migrations are added. Plugin manifests
advance to 1.6.1. Installing this source release does not automatically refresh
an already installed plugin cache; update or reinstall the plugin to load the
new skill instructions. Use [v1.6.0](v1.6.0.md) to return to the previous
instructions.
