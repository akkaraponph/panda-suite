# v1.7.0

Panda Suite adds two standalone specialists, bringing the catalog to 25 skills.

- **Panda Setup** initializes projects and prepares existing repositories for
  agent-assisted development. It checks current tool versions, preserves
  existing instructions, reviews ignore rules, and reports observed setup checks.
  See the [Panda Setup guide and evaluation](panda-setup.md).
- **Panda Logo** explores, creates, refines, and audits visual identities. It
  supports editable SVG, raster exports, favicons, banners, and brand-kit
  archives when the host supplies the required tools. See the
  [Panda Logo usage guide](panda-logo.md).

Panda Lead can route requests to either skill. Both can also be installed and
invoked independently.

## Verification and limits

The local release candidate was checked with the suite validator, tooling unit
tests, Codex plugin and standalone discovery, Claude Code manifest validation,
the documentation build and link checker, and the Logo reviewer controls.

Logo creation and the no-renderer fallback were exercised in blind Codex
trials. The creation trial produced requested files, but its visual verification
claim lacked a recorded viewing action. Additional behavioral scenarios and
interactive plugin invocation remain unrun. See the
[Logo trial record](../tests/results/logo/comparison.md) and the
[Setup trial record](../tests/results/setup/summary.md) for scope and limits.

## Compatibility and recovery

The source plugin manifests advance to 1.7.0. Existing installations may need
an update or reinstall to discover the new skills. There are no runtime
migrations or new required runtime dependencies. To revert a local installation,
use the source from [v1.6.3](v1.6.3.md).
