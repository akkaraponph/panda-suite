# v1.7.1

Panda Suite credits the original Buddhist Method project by nai0om and documents
the akkaraponph fork used as the Suite's pinned source. The attribution appears
in the English and Thai READMEs and the published source notices.
See the [original project](https://github.com/nai0om/buddhist-method) and
[the fork](https://github.com/akkaraponph/buddhist-method).

The source notices also identify Udomsak as the copyright holder in the
[original MIT license](../skills/buddhist-method/LICENSE).

The plugin manifests and installation examples advance to 1.7.1. GitHub Pages
includes these release notes, the attribution, and an updated latest-release
section.

## Compatibility and recovery

This patch updates attribution, documentation, and version metadata. The catalog
contains 25 skills. No migrations or additional runtime dependencies are required.
Existing installations can update to the 1.7.1 tag. To recover a previous local
installation, reinstall from [v1.7.0](v1.7.0.md). The preceding version remains
available as a GitHub release.

GitHub Pages deployment is verified through the Documentation workflow and the
published release and source-notices pages. A failed workflow or missing published
attribution requires correction before reporting the site update complete.
