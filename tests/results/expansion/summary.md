Seven task-use cases were run in two grouped evaluator contexts. These are not
independent comparative samples. No causal improvement, token savings, or universal
reliability is claimed. Task agents received prompts and raw fixtures, not grading
answers. Instruction loading was by file reads, not simulated invocation.
